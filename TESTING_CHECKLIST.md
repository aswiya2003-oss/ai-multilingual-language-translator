# Testing Checklist

Record the date, operating system, Python version, hardware, model versions, and test-set details.

- [ ] Application starts without errors.
- [ ] First model download completes.
- [ ] English → Hindi translation.
- [ ] English → Telugu translation.
- [ ] Hindi → English translation.
- [ ] Telugu → English translation.
- [ ] Additional language pairs verified.
- [ ] Empty text validation.
- [ ] Same-language behavior.
- [ ] Long text translated in chunks.
- [ ] WAV/MP3/M4A transcription.
- [ ] Confirm source language after speech recognition.
- [ ] TXT document extraction/export.
- [ ] DOCX extraction/export.
- [ ] Text-based PDF extraction/export.
- [ ] Scanned PDF limitation shown clearly.
- [ ] Unicode scripts display correctly.
- [ ] BLEU/chrF script runs on aligned sample files.
- [ ] Translation latency and memory use recorded.
- [ ] Errors and output quality reviewed by fluent speakers.
